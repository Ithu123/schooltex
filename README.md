# Description
This is a Tex-Repo for useage in schools, Currently it is only available in german. 

# Cloning
If you want to clone this to your local machine, youd have to clone it without the project folder 

```git clone git@github.com:Ithu123/schooltex.git .```

# Dokumentation
- Ausführliche Dokumentation mit Beispielen: [doc/latex/schooltex/schooltex-doku.pdf](doc/latex/schooltex/schooltex-doku.pdf)
- Cheatsheet (eine Seite, quer): [doc/latex/schooltex/schooltex-cheatsheet.pdf](doc/latex/schooltex/schooltex-cheatsheet.pdf)

Beide werden aus den `.tex`-Dateien im selben Ordner mit `pdflatex` erzeugt (Doku: dreimal übersetzen).
